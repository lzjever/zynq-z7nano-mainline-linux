Zynq Z7-Nano 主线 Linux 实战手册

从开箱到自主启动:一次真实移植的完整复盘,新手可以直接跟做

一天,给 Zynq-7000 换上一颗现代的心脏

很多 Zynq 开发板出厂带的还是 2018 年的 PetaLinux:内核停在七年前,SSH 连不上新系统,安全补丁早已断流。这本手册记录的是一次真实完成的移植:不开 Vivado、不用厂商 SDK,纯开源工具链,把一块 MicroPhase Z7-Nano 刷成主线 U-Boot + Linux 6.18 + Debian 13——而且,从开箱到自主启动,只用了一天。

白天开箱、构建、制卡;深夜用 JTAG 一层层排查"串口全静默"的幽灵故障,最终在当天夜里看到登录提示符。中间踩的每一个坑,都有完整的"症状、定位、修复"记录,原样整理给你——希望你踩过的坑,比我们少。

和官方教程比,这本手册强在哪

官方指南假设你围绕 Vivado 与 PetaLinux 工作,工具重、版本绑死;零散的社区教程常常只给命令不给"为什么",一出错就卡死。本手册的取舍是:

  • 路线全开源:能不用的专有工具一律不用,每个环节都有开源替代(第 03 章逐环节分析);
  • 每个关键操作讲"是什么、为什么",不只给命令——真正卡住你的从来不是命令本身,是命令背后的机制;
  • 失败不删档:被 BootROM 拒收的镜像、打包器踩过的格式坑,原样留档示警(第 02、07 章);
  • 代价:以一块具体板子为纲,通用性靠"讲清楚哪些参数因板而异"来补——这类参数手册里都用加粗标出。

  • 不是 FPGA 教程——全程只动 PS(ARM 侧),不写一行 Verilog,PL 开垦放在第 08 章路线图;
  • 不是内核开发教程——我们不改内核源码,直接用主线,只做设备树移植;
  • 不要求你有嵌入式移植经验——但假设你会基本的 Linux 命令行,能在一台 Ubuntu(实体机或虚拟机)上安装软件包;

封面 FAQ:四个最常被问的问题

Q1:需要会 FPGA / Verilog 吗?

完全不需要。全程只动 PS(ARM 侧),PL 一根毛都不碰——这正是本手册敢号称"新手可跟做"的底气。想学 FPGA?那是第 08 章路线图里的"进阶方向",先把 Linux 跑起来再说。

Q2:我的板子不是 Z7-Nano,能跟吗?

能。启动链理论、构建流程、JTAG 方法论对任何 Zynq-7000 板都成立;要换的只是"因板而异"的参数:设备树(串口/内存/PHY)、FSBL 里的 ps7_init(直接复用你板子的厂商 FSBL 即可)。第 01 章末尾有专门的换板提示。

Q3:我的电脑没有 24 核,能编吗?

能。核数只影响编译速度,不影响可行性——把 -j24 换成 -j$(nproc),多等一会儿而已。实测用的 Ubuntu 24.04 自带 GCC 13.3,对交叉编译完全够用。

Q4:会把板子刷坏吗?

本手册走 SD 卡启动,不动板载闪存——卡刷坏了换张卡,板子毫发无伤。真到万不得已,还有 JTAG 这条"物理层救援通道"(第 06 章的方法,第 08 章的方向二),BootROM 在 JTAG 档永远等你。

写法约定

为了让代码块"抄了就能用",全册统一以下约定:

  • 代码块里以 # 开头的行是注释,不是要执行的命令;
  • 标注"板上"的命令,在板子的串口终端里执行;标注"主机"的,在你电脑的 Ubuntu 里执行——分清这两边,能避免一半的新手错误;
  • 正文里的行号(如 L63)指仓库 code/ 下对应源码文件的行号,方便对照;
  • 所有路径默认相对于本手册仓库根目录(准备清单里 git clone 的目标),涉及绝对路径的命令会在注释里说明。

开始前的三条建议

师兄的碎碎念
  • 别跳过开箱体检:出厂系统不只好玩,它是后面所有排障的"对照组"——厂商 BOOT.BIN 是已知好样本,出厂数据是你的基准线;
  • 遇到"没反应"先查物理层:跳线档位、线材好坏、插没插对口——这三样排除了,再去怀疑软件;手册里每个坑都对应一条"第一反应";
  • 随手记现象:每一步成功时串口长什么样、失败时长什么样,记下来——深夜排雷时,这些记录就是你的证据链。

学完你能得到什么

收获清单
  • 讲得清 Zynq-7000 四级启动链(BootROM → FSBL → U-Boot → 内核):每一级在哪、干什么、坏了是什么症状;
  • 掌握一套全开源构建流程:apt 交叉工具链 + 主线 U-Boot + 主线内核 + Debian rootfs,全程不装 Vivado;
  • 会写 Zynq 设备树:串口别名、内存大小、以太网 PHY、USB 模式四处关键改动;
  • 看得懂 BOOT.BIN 二进制:能解析分区头、算 XOR 校验和、写对分区表结束标记;
  • 拥有一套 JTAG 分层定位法:PC 停在哪个区间,就知道卡在 ROM、FSBL、U-Boot 还是内核;
  • 对 17 个真实坑免疫:每个坑都有"症状 → 定位 → 修复"的完整链条,而不是一句"注意别踩"。
